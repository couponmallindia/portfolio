NISARG FAMILY GUEST HOUSE — WEBSITE REDESIGN
============================================

Files:
- index.html: Home page
- about.html: About the guest house and amenities
- gallery.html: Filterable photo gallery with lightbox
- contact.html: Contact details and WhatsApp enquiry form
- assets/styles.css: Responsive site styles
- assets/script.js: Mobile menu, gallery filters/lightbox, enquiry form
- images/: Original supplied images and assets preserved

Before publishing:
1. Replace YOUR-DOMAIN.example in sitemap.xml and robots.txt with the real website domain.
2. Update the JSON-LD "url" field in each HTML page with the real canonical URL.
3. Test phone numbers, room details, facilities and image display on your hosting.
4. The contact enquiry form opens WhatsApp; it does not submit to a server or create a booking.
5. Check current availability, rates and local beach conditions before publishing claims about them.

The website is static HTML5/CSS/JavaScript and can be uploaded to standard shared hosting.
